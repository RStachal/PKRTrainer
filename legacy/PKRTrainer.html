Rule cards (shrnutí + okrajové handy)

A) OPEN (15–25 BB) starter A1) HJ: 22+, A2s+, AJo+, KTs+, KQo, QTs+, JTs, T9s, 98s, 87s. Okraje: nejnižší suited konektor = 87s; nejnižší offsuit A = AJo; nejnižší offsuit K = KQo. A2) CO: 22+, A2s+, ATo+, KTs+, KTo+, QTs+, QTo+, JTs, J9s, T9s, 98s, 87s, 76s, 65s, 54s, + okraje 97s, 86s. Okraje: nejnižší suited konektor = 54s; nejnižší suited A = A2s; nejnižší offsuit A = ATo; nejnižší offsuit Q = QTo. A3) BTN: CO range + A2o–A9o + pár suited broadwayů navíc. Okraje: nejnižší offsuit A = A2o. B) ISO (15–25 BB) B1) IP (CO/BTN): default iso 2.5x–3x při 15–20 BB; 3x–3.5x při 21–25 BB. 3.5x jen exploit (loose-passive limper, pasivní blindi, value plán na low SPR). B2) ISO range (value-heavy): 22+, A2s+, A9o+, K7s+, Q8s+, J8s+, T9s, 98s, 87s. Pozn.: malé/střední páry 22–66 vs early limper (UTG/HJ) při 15–20 BB často preferuj OVERLIMP; ISO jen menší sizing (2.5x–3x) a spíš exploitově. Okraje: nejnižší suited K = K7s; nejnižší suited Q = Q8s; nejnižší suited J = J8s; nejnižší konektor = 87s. B3) Overlimp okraje (volitelně): 22–66, 54s–T9s. Okraje: nejnižší = 54s. B4) ISO 3x–3.5x při 15 BB není “o fold equity”, ale o plánu hrát nízký SPR. Pokud hand není happy low‑SPR, preferuj menší ISO nebo OVERLIMP. C) BB DEFEND podle sizingu C1) vs 2x: široce. Okraje: 43s, K2s, Q5s, J7s. C2) vs 2.5x: ořezat offsuit junk. Okraje: 54s, A8o, K4s. C3) vs 3x: ještě víc ořezat. Okraje: 76s, ATo, K7s. C4) 3bet value: TT+ AQ+ (vs HJ tighter). Bluff: A5s–A2s (hlavně vs CO/BTN, menší sizing). C5) BB_DEFEND_2X (vs CO/BTN steal 2x): stejný baseline jako C1, ale otázky jsou cíleně na okraje (marginální CALL i close FOLD). Marginální CALL typicky: K2s–K6s, Q5s–Q8s, J7s–J9s, T7s–T9s, 98o, T9o, 43s–76s, 86s/97s. Close FOLD typicky: slabé offsuit Kx/Qx/Jx/Tx (např. K2o–K8o, Q2o–Q8o, J2o–J7o, T2o–T7o). D) REJAM 15–20 BB vs CO/BTN open D1) Value: 77+ AJs+ AQo+ KQs. Okraje: nejnižší pocket = 77; nejnižší suited A = AJs; nejnižší offsuit A = AQo. D2) Semi (volitelně): 55–66, ATs–A2s, občas AJo, KJs/QJs selektivně. Okraje: nejnižší suited A = A2s; nejnižší pocket = 55. E) SB OPEN 15–25 BB E1) Default open 2x; 2.5x jen exploit. E2) Starter SB open range: 22+, A2s+, A2o+, K2s+, K8o+, Q4s+, Q9o+, J6s+, J9o+, T6s+, T9o+, 96s+, 86s+, 76s+, 65s+, 54s+, 98o+. Okraje: nejnižší suited K = K2s; nejnižší offsuit K = K8o; nejnižší suited Q = Q4s; nejnižší offsuit Q = Q9o; nejnižší suited konektor = 54s. F) BVB_AFTER_3BET (SB open -> BB 3bet; 15–25 BB) F1) Value 4bet jam: 99+ AJs+ AQo+ KQs. Okraje: nejnižší pocket = 99; nejnižší suited A = AJs; nejnižší offsuit A = AQo; nejnižší suited broadway = KQs. F2) Call vs 3bet: 55–88, ATs–A6s, AJo, KTs/KJs, QTs/QJs, JTs, T9s, 98s, KQo. Okraje: nejnižší pocket = 55; nejnižší suited A = A6s; nejnižší suited konektor = 98s; nejnižší offsuit broadway = KQo. F3) Semi 4bet jam (mix / exploit): A5s–A2s. Okraje: nejnižší = A2s. H) TURN (nové lekce) H1) PFR barrel DRY: pokračuj s value + strong draw + část overs/backdoor (hlavně IP). Cíl: nevyhasnout po flopu. H2) PFR barrel WET: selektivněji; méně bluffů bez equity, protože continuing range je silná. H3) Delayed cbet IP: po flop checkbacku často betuj turn s value/draw + dobré overkarty. H4) DEFENDER vs barrel: neoverfolduj. Call s made hand + draw, raise value-only (a pár draw OOP), fold air. I) RIVER (nové lekce) I1) Valuebet: nevynechávej value (top pair+). Bet často malý/rozumný, ne overjam. I2) Thin value IP: betuj top pair a lepší; se 2nd pair jen když runout není scary a soupeř má dost bluffcatchů. I3) Checkback: když soupeřova calling range dominuje a value je příliš tenká. I4) Bluffcatch: měj minimální call range (typicky top pair+, někdy 2nd pair IP). Jinak tě soupeři přebluffují. I5) Value-raise: raise na riveru defaultně jen value-heavy (2pair+/set+).
