# Flop lists for GTO+ database families

Tyto soubory jsou jednoduchý pracovní formát: jeden flop na řádek.

GTO+ video dokumentace ukazuje workflow pro ukládání/načítání seznamu flopů, ale veřejné textové schema není v dokumentaci přesně popsáno. Pokud tvoje instalace GTO+ při importu flop listu očekává jiný textový layout, udělej prosím v GTO+ jeden ruční export flop listu a nahradíme tento formát přesně podle něj.

Aktuální účel:

- dát operátorovi jasný seznam flopů pro každou GTO+ database family,
- zabránit míchání různých spotů do jedné databáze,
- připravit následné mapování exportů zpět do PKRTrainer.
