# Pio-like predef range files

Tato složka obsahuje stejné textové range stringy jako `../ranges/`, ale je oddělená kvůli GTO+ workflow, kde se často používá Pio-like/predefined range import.

Pokud automatický import konkrétní instalace GTO+ nevezme soubory přímo, použij je jako copy/paste zdroj do range editoru.

Range stringy jsou testovací, ne produkčně schválené.
